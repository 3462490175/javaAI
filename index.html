智能心理健康 AI 咨询系统介绍页面

基于 Spring Boot 3 + Spring AI + Vue 3 构建的企业级全栈项目。
提供流式打字机对话、无状态 JWT 鉴权与长连接上下文记忆。

查看源码
⚡
AI 流式极速响应
集成 Spring AI 对接大模型，基于 SSE (Server-Sent Events) 技术实现打字机级别的流式输出，彻底告别传统 HTTP 长时间等待。
🔐
企业级安全认证
基于 Spring Security + JWT 实现前后端分离架构下的无状态鉴权。自定义过滤器拦截解析 Token，保障接口安全。
🧠
智能上下文记忆
使用 Redis 与 ChatMemory 缓存多轮对话上下文，确保 AI 能够记住历史聊天记录，提供连贯、共情的心理疏导体验。
🛡️
全局异常与校验
主导封装统一响应格式（Result）与全局异常处理（RestControllerAdvice），结合 Spring Validation 实现入参深度校验。

🛠️ 全栈技术生态
